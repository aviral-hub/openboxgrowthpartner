Database Architecture & Keys

Analyze foreign relationships, isolate primary primary indexing constraints, and verify database integrity rules.

Module Objectives

  • Isolate Primary Keys (PK) and Foreign Keys (FK).
  • Formulate clear Data Dictionaries.
  • Map relational cardinality between operational entities.
  • Validate integrity constraints across live tables.

Part 1 — Database Primary Keys

A Primary Key (PK) ensures every record in a table maintains unique identity integrity. It prohibits null values and strictly guarantees unique row-level lookups.

Foreign Keys (FK) construct foreign reference constraints between relational entities, ensuring referential integrity across transactional boundary layers.
