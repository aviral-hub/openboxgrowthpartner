Evolution of Java

Java originated in the early 1990s and was initially called Oak.

Key Founders

The material identifies James Gosling, Patrick Naughton, Chris Warth, Ed Frank and Frank Sheridan as key founders.


Original Design Goal

Java was originally intended as a platform-neutral language for embedded software in devices. The goal was to move away from platform and OS-specific compilers toward portable, platform-independent code.

03 Loading Class Loader loads bytecodes
04 Verify Verifier checks bytecodes
05 Execute JVM executes the program

Inside the JVM

Key concepts from the module.

Java Virtual Machine

The output of the compiler is bytecode. The bytecodes are executed by the JVM. The provided material describes the JVM as platform-specific.

Execution Engine

The material describes interpretation, just-in-time compilation and adaptive optimization as mechanisms involved in execution.

Adaptive Optimizer

The virtual machine can identify heavily used areas of code and compile those areas into native code while other code continues to be interpreted.

Class Loader

The Class Loader loads compiled Java bytecode into the JVM. The source material also highlights its security and network mobility importance.
