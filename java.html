Days 1 - 2 Core Programming Language Basics

Day 2 Benchmark Exercises (IDE Practice)

  • Write a program to accept a number N and print whether it is positive, negative, or zero
  • Write a program to accept two numbers and print the greater value
  • Write a program to accept a number N and print whether it is EVEN or ODD
  • Write a program to accept two numbers and print whether their sum is EVEN or ODD
  • Print all numbers from 1 to 100 (1 2 3 4 ... 100)
  • Print alternate numbers starting from 1 to 99 (1 3 5 7 ... 99)
  • Print alternate numbers starting from 0 to 100 (0 2 4 6 ... 100)
  • Print numbers backwards from 100 to 0 (100 99 98 ... 0)
  • Print numbers backwards from 100 to 1 skipping 2 numbers (100 97 94 ... 1)
Day 3 Division & Modulo Operators
Objective: Learn the practical application of division / and modulo % operations in IDE (Eclipse / VS Code / vi).
  • Is Even? — Return 2 if even, 1 if odd. (Zero is Even)
  • Is Odd? — Return 2 if odd, 1 if even. (Zero is NOT Odd)
  • Return Last Digit: Return units place as positive number (e.g. -197 -> 7)
  • Return Second Last Digit: Return tens place as positive number. Return -1 if single digit.
  • Sum of Last Digits: int addLastDigits(int input1, int input2) ignoring sign.
