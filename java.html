Evolution of Java

Java originated in the early 1990s and was initially called Oak.

Key Founders

The material identifies James Gosling, Patrick Naughton, Chris Warth, Ed Frank, and Frank Sheridan as key founders.


Original Design Goal

Java was originally intended as a platform-neutral language for embedded software in consumer devices. The goal was to move away from OS-specific compilers toward portable, platform-independent code.

The core architecture breaks execution into five distinct phases: Edit → Compile → Loading → Verify → Execute.

The 5 Phases of a Java Program

Remember this sequence before taking the quick quiz.

01 Edit Create the .java source file
02 Compile javac creates .class bytecode
03 Loading Class Loader loads bytecodes
04 Verify Verifier checks bytecodes
05 Execute JVM executes the program

Inside the JVM

Key internal components and execution mechanisms.

Java Virtual Machine

The output of the compiler is platform-neutral bytecode. The bytecodes are executed by the JVM, which itself is platform-specific.

Execution Engine

Combines direct interpretation with Just-In-Time (JIT) compilation to convert bytecode to native machine instructions efficiently.

Adaptive Optimizer

Identifies heavily used code paths ("hotspots") and compiles them directly into native binary code while interpreting the rest.

Class Loader

Dynamically loads compiled Java `.class` files into runtime memory while reinforcing security boundaries.
